# 📚 Guide Complet: Les 10 Méthodes Essentielles du Secteur A

## 🎯 Objectif
Apprendre par cœur les méthodes VRAIMENT classiques du secteur A en 4 jours pour réussir votre CC.

---

# 1. 🔬 MICROSCOPIE OPTIQUE (Photonique)

## Définition
Observation d'échantillons à l'échelle cellulaire (résolution ~200 nm).

## Caractéristiques clés
- **Grossissement utile**: 400-1000x
- **Limite de résolution**: ~200 nm (0.2 μm)
- **Sourcesphotoniques**: Lumière visible

## Types
- **Fond clair**: Visualisation de cellules colorées
- **Fond noir**: Cellules vivantes sans coloration
- **Contraste de phase**: Structures non pigmentées sans coloration

## Formule clé
**Grossissement total = Grossissement oculaire × Grossissement objectif**
(exemple: 10x × 40x = 400x)

---

# 2. ⚗️ FIXATION CELLULAIRE

## Objectif
Stabiliser les structures cellulaires et les protéines pour arrêter la dégradation.

## Fixateurs courants

### Pour microscopie optique
- **Formaldéhyde (4%)**: Le classique, rapide, bon marché
- **Ethanol (70-100%)**: Alternative, fixe vite
- **Acétone**: Rapide

### Pour microscopie électronique (MET)
- **Double fixation**:
  1. **Glutaraldéhyde (2.5%)**: Fixe les protéines
  2. **Tétraoxyde d'osmium (OsO₄)**: Contraste les lipides + prépare aux ultra-coupes

## Règle d'or
> La première fixation est CRITIQUEMENT importante - si elle est mauvaise, tout le reste échoue!

---

# 3. 💧 DÉSHYDRATATION

## Pourquoi?
Remplacer l'eau pour permettre l'inclusion en paraffine (hydrophobe).

## Protocole classique
```
Tissu fixé
    ↓
Éthanol 70% → 5-10 min
    ↓
Éthanol 90% → 5-10 min
    ↓
Éthanol 100% → 10 min (2-3 fois)
    ↓
Prêt pour la paraffine
```

## Pourquoi progresser?
- Transitions brusques = déformation/rupture
- Progression permet à l'eau de s'échapper graduellement

---

# 4. 📦 INCLUSION EN PARAFFINE

## Objectif
Infiltrer le tissu avec une substance dure pour faire des sections fines.

## Processus
1. **Pré-imprégnation**: Tissu + paraffine à 37°C (liquide)
2. **Imprégnation**: À ~60°C (plus chaud)
3. **Polymérisation**: Refroidir = paraffine solidifie
4. **Résultat**: Bloc de paraffine contenant le tissu

## Alternative modernes
- **Résines (Spurr, Epon)**: Pour MET (meilleure résolution)
- **Paraffine**: Standard en histologie

---

# 5. ✂️ MICROTOMIE (Coupes)

## Définition
Découper le bloc de paraffine en sections très fines avec un microtome.

## Épaisseurs
- **Microscopie optique**: 5-10 μm
- **Microscopie électronique**: 70-90 nm (ultra-fines!)

## Technique
- Lame chauffée (~30-40°C) pour faire "dérouler" le ruban
- Les coupes se collent naturellement par la chaleur

---

# 6. 🎨 COLORATIONS HISTOLOGIQUES

## Pourquoi?
La plupart des structures cellulaires sont incolores naturellement → besoin de couleur pour visualiser.

## Colorants courants

### H&E (Hématoxyline & Éosine) - LE STANDARD
| Structure | Couleur |
|-----------|---------|
| Noyau | Bleu-violet |
| Cytoplasme | Rose |
| Fibres collagène | Rose clair |

### Gram (bactéries)
- **Gram positives**: Violet
- **Gram négatives**: Rose

### PAS (Periodic Acid-Schiff)
- **Polysaccharides & glucides**: Magenta/rose

### Masson (fibres)
- **Collagène**: Bleu
- **Muscle**: Rouge

# 7. ⚡ ÉLECTROPHORÈSE SUR GEL D'AGAROSE

## LE CLASSIQUE absolue pour la biologie moléculaire!

## Définition
Séparer les molécules d'ADN selon leur taille dans un champ électrique.

## Principe
- **Les charges**: ADN a des phosphates (négatifs)
- **Le champ**: Force les molécules dans le gel
- **Le résultat**: Plus l'ADN est gros, moins il migre vite

## Protocole type
```
1. Préparer gel d'agarose (0.8%)
2. Couler le gel dans le moule
3. Laisser solidifier
4. Déposer l'ADN + tampon de charge
5. Appliquer 100V pendant 1 heure
6. Visualiser sous UV
```

## Marqueurs importants
- **Marqueur de poids moléculaires (ladder)**: Pour comparer
- **Tampon TAE/TBE**: Pour la conductivité et le pH

---

# 8. 🧪 EXTRACTION D'ADN (CTAB ou phénol-chloroforme)

## Objectif
Isoler l'ADN pur à partir de cellules ou tissus.

## Méthode CTAB (la plus courante)
```
1. Broyage du tissu → libérer les cellules
2. Lysis (lyse): 
   - Sel (NaCl) rompt les liaisons ioniques
   - CTAB (détergent) rompt les membranes
   - Eau distillée dilue
3. Chélation par EDTA:
   - Piège les divalents (Mg²⁺, Ca²⁺)
   - Désactive les DNases
4. Centrifugation: ADN précipite
5. Lavage: Enlever contaminants
6. Réhydratation: Dissolution dans l'eau
```

## Points clés
- **EDTA**: Éssential - protège de la dégradation
- **CTAB**: Complexe avec les polysaccharides (enlève contaminants)
- **pH basique**: ADN reste en solution

---

# 9. 🔥 PCR (Réaction en Chaîne par Polymérase)

## L'amplification d'ADN!

## Cycle thermique
```
Dénaturation:  94°C, 15 sec      (briser les doubles brins)
   ↓
Hybridation:   55°C, 30 sec      (amorces s'attachent)
   ↓
Élongation:    72°C, 1 min/kb    (Taq synthétise)
   ↓
Répéter 30-35 fois
```

## Composants essentiels
1. **Template ADN** (modèle)
2. **Amorces** (primers)
3. **Taq polymérase** (enzyme)
4. **dNTPs** (briques)
5. **Tampon** (pH, Mg²⁺)

## Après PCR
- Vérifier par électrophorèse
- Purifier si nécessaire
- Cloner ou séquencer

# 10. 📊 CHROMATOGRAPHIE (affinité, exclusion stérique, échanges d'ions)

## Définition générale
Séparation de molécules selon leurs propriétés physiques en les faisant migrer sur une colonne.

## Types courants

### 1. Chromatographie d'exclusion stérique (SEC) - "Gel filtration"
**Sépare par TAILLE**
- Grosses molécules → sortent en premier
- Petites molécules → sortent en dernier
- **Usage**: Purifier protéines

### 2. Chromatographie d'échange d'ions
**Sépare par CHARGE**
- Protéines positives → retenus sur colonne négative
- Protéines négatives → retenus sur colonne positive
- **Usage**: Purifier protéines

### 3. Chromatographie d'affinité
**Sépare par LIAISON SPÉCIFIQUE**
- Protéines cibles → s'attachent au ligand
- Autres → passent sans rétention
- **Usage**: Isoler protéines précises (ex: anticorps)

### 4. Chromatographie liquide (HPLC)
**Haute résolution**
- Séparation très précise
- Phase mobile = solvants de différents pH/force ionique
- **Usage**: Analyser des protéines/peptides complexes

# 🎯 SECRETS DE RÉVISION

## 1. **Ordre logique des étapes**
Les protocoles suivent TOUJOURS une logique:
- Préparer l'échantillon
- Isoler la molécule/structure
- Analyser/Visualiser
- Interpréter

## 2. **Les "détails critiques" que les profs adorent**
- Pourquoi utiliser de l'EDTA **précisément**?
- Pourquoi 30-35 cycles de PCR et pas 50?
- Pourquoi OsO₄ **après** le glutaraldéhyde?

## 3. **Dessiner = Comprendre**
Dessinez mentalement:
- Les structures fixées
- Les molécules migrant
- Les protéines se séparant

## 4. **La règle des 80/20**
- 20% des détails = 80% de vos points
- Concentrez-vous sur les **immanquables**
